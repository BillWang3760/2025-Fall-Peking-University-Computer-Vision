# 2025-Fall-Peking-University-Computer-Vision
欢迎访问我的Repository！

本仓库基于25秋北京大学信息科学技术学院《计算机视觉》的六次作业、作者本人的思考与解答以及前人的智慧搭建而成，主要面向25秋之后选修这门课程的学习者，
旨在通过一些有益的提示使他们少走弯路或减小无谓的时间损耗。

本仓库提供以下内容：
1. 作业的完整代码实现；
2. 图文并茂的作业报告；
3. 完成作业过程中作者使用或生成的所有图片（Homework 2部分图片除外）。

本仓库**不**提供以下内容：
1. 作业内容原文件；
2. Homework 5、6中的各模型权重。
